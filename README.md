## 研究对象

小鹏汇天（XPENG AEROHT）分体式飞行汽车「陆地航母」，重点分析其飞行体 **X3-F**：

- 陆行体：三轴六轮、800V 碳化硅增程平台、CLTC 续航 1000 km 以上、可为飞行体补能 5—6 次、C 照可驾驶
- 飞行体：六轴六桨双涵道、碳纤维机身、270° 双人座舱、最大起飞重量 560 kg、有效载重 200 kg
- 关键进展：TC 2024-03 受理、PC 2025-05 受理、截至 2026-10 未取证、已完成局方试飞

## 报告结构

1. 执行摘要
2. 研究设计与证据边界（证据分级：官方 / 监管 / 第三方 / 本文估算）
3. 产品定义与谱系
4. 系统架构与关键技术（分体式构型、飞行体冗余、能量链、适航审定基础）
5. 技术可行性（四层验证状态、悬停续航参数化估算、技术路线对比、制造与供应链）
6. 应用场景（场景矩阵：文旅 / 高端个人 / 应急 / 通勤）
7. 市场可行性（需求信号、TAM-SAM-SOM 漏斗、成本结构、文旅运营模型、竞争格局）
8. 政策、基础设施与生态
9. 风险清单与 Go/No-Go 判据
10. 结论

## 方法与口径

- **证据分级**：全文对每个关键数据标注来源等级，区分「企业声明」与「工程结论」。
- **三个必须坚持的口径**：受理 ≠ 取证、试产 ≠ 量产、订单 ≠ 交付。
- **参数化估算**：飞行体航程/续航未公开，本文用悬停功率模型给出 7—16 分钟的区间，并明确标注为「本文估算」。
